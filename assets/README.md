Alert tones, generated by `tools/make_chime.py`:

| File | Plays at |
|---|---|
| `chime.wav` | distraction nudge (also the recorder's start/stop beep) |
| `chime_slow.wav` | stage 3, four pulses at 1 Hz |
| `looming.wav` | stage 4, 3 Hz pulses rising 30 dB |

Spoken prompts go in `voice/`, recorded on the Pi with the INMP441:

    python3 tools/record_prompts.py --list
    python3 tools/record_prompts.py --only open_window

A familiar voice is measurably more arousing than a synthetic one, which is
itself a testable claim worth a line in the report. Any prompt not yet
recorded is skipped, so the tones work on their own. Keep each under two
seconds: a long prompt is a distraction in its own right.
